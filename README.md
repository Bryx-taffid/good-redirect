# Good Redirect

> ⚠️ **Work in progress:** this project is currently in active development. The features described below are planned and **do not exist yet**.

Good Redirect is a browser extension concept designed to help people reduce unwanted online habits.

Instead of relying on willpower in the moment, the extension aims to redirect visits from distracting or harmful websites to pages that reinforce healthier choices.

## Why this project exists

Many online behaviors happen automatically: opening familiar sites, doom-scrolling, or returning to habits we want to stop. Good Redirect is meant to add a pause and a reminder at exactly that moment.

The goal is simple: replace unhelpful defaults with intentional alternatives.

## How it is intended to work

After installing the extension, users will be able to:

1. Select a behavior preset to avoid (for example, porn or gambling).
2. Configure a personal redirect URL for that preset.
3. Get redirected each time a matching website is opened.

Example:
- A user enables the porn preset.
- They set a redirect URL to a helpful video, article, or personal motivation page.
- When they try to open a matching site, Good Redirect sends them to that chosen alternative instead.

## Planned features

- Presets for common unwanted behavior categories
- Custom redirect targets per category
- Simple, focused configuration UI
